# Texture Generator

`Tools > TakoLib > Texture Generator` から開きます。

## 生成

- Perlin / Value / Fractal（fBm）/ Billow / Ridged / White ノイズ。
- Voronoi / Hexagon / Triangle のセル内UVとセルID。
- 解像度は各軸16～4096px。シード、セル数、フラクタルのオクターブ・強さを設定できます。
- 各RGBAチャンネルに、同じパターンの Value / U / V / CellId / Zero / One を個別に指定します。
- 「UV + セルID」で R=U、G=V、B=CellId、A=1 を設定します。
- 「シームレス生成」で両軸に周期を持つパターンを生成します。Hexagon/Triangleの縦セル数は偶数に切り上げます。
- 設定変更後、操作が約0.2秒落ち着くと最大256pxのプレビューを自動生成します。ウィンドウを開いたときにも生成し、「プレビューを再生成」で手動更新できます。「PNGを保存」で指定解像度の8bit RGBA PNGを出力します。保存用の生成はキャンセル可能です。
- RGBと各チャンネルの単独表示、3×3タイル表示で結果を確認できます。RGB表示ではアルファを無視します。
- プレビューの表示寸法は従来の約2/3です。生成解像度は変わりません。
- 「RGBA別のシード」で各チャンネルのシード値を指定できます。有効化時は共通シードから初期化します。
- 「トーンカーブを適用」でRGB共通と各RGBAのカーブを編集できます。RGB共通→各チャンネルの順で適用し、Aは専用カーブのみ使用します。プレビューに即時反映し、保存PNGにも適用します。
- トーンカーブ欄のヒストグラムで調整前（灰色）と現在の出力（色付き）の分布を重ねて表示します。RGB/R/G/B/Aを切り替えられ、横軸は画素値0～1、縦軸は画素数（両分布共通の最大値で表示倍率を調整）です。RGB表示は3チャンネルの合算です。分布はプレビュー画像から集計するため、保存解像度での厳密な分布とは異なる場合があります。

### UVの定義

Voronoiは最近傍シードからの相対座標を `0.5 + 差分/2` に変換します。各不規則セルを0～1いっぱいに正規化するものではありません。
Hexagonはセルの外接矩形内UV、Triangleは重心座標の2成分です（第3成分は `1-U-V`）。
セル境界ではUVとCellIdが不連続になります。シームレス生成でも、この意図した不連続は残ります。
ValueはVoronoi/Hexagonでは中心からの距離、Triangleでは最も近い辺までの距離を正規化した値です。
Whiteはセルごとの独立乱数です。

### モザイク用の中心UV

「モザイク用 セル中心UV (RG)」で R=CenterU、G=CenterV、B=0、A=1 に設定します。
各セルを中心点の画像UVで塗りつぶします。Voronoiはそのセルの生成点、Hexagonは六角形の中心、Triangleは重心です。
このテクスチャのRGを別画像のサンプリングUVに接続すると、セルごとに同じ画像色を参照できます。
シームレス時は中心UVを0～1に循環し、非シームレス時は画像範囲にクランプします。
VoronoiではR/Gのシードを揃えてください。プリセットボタンはGのシードをRに合わせ、トーンカーブを無効にします。
Hexagon/TriangleのシードはセルIDを変更し、規則的な形状・中心位置は変更しません。
中心UVを含む出力はPointフィルターでインポートし、セル境界での座標補間を防ぎます。PNGのUV精度は8bitです。

正六角形・正三角形にする場合、画像の幅/高さを `横セル数 / (実効縦セル数 × 0.8660254)` に合わせます。
異なる比率では図形が伸縮します。

生成データはsRGB無効、非圧縮、ミップマップなしでインポートします。シームレス時はWrap ModeをRepeatに設定します。
PNGは8bitのためUVに量子化が発生します。小さなセルや高オクターブを低解像度で出力するとエイリアシングが発生します。

## 50%オフセット

ウィンドウの「50% オフセット」、またはテクスチャの右クリック `TakoLib > Offset Texture 50%` から利用できます。
左右・上下の移動をそれぞれ指定し、はみ出した画素を反対側へ循環します。Read/Writeは不要です。
出力は元画像の解像度とsRGB設定を引き継ぎ、RGBAを保存します。読み取り対象はUnityにインポートされた画像なので、インポート時の縮小・圧縮の影響は含まれます。
自動プレビューでは元画像を最大256pxに縮小してオフセットとフェードを計算します。保存は元画像の解像度で処理します。
元画像と同じ保存パスは拒否します。

偶数サイズでは正負どちらに50%ずらしても同じ結果になります。奇数サイズは半分を切り捨て、右・上へ移動します。
通常は継ぎ目を中央へ移動します。「フェードでシームレス化」を有効にすると、元画像の中央の縦帯・横帯を重ねて中央の継ぎ目を覆います。
縦帯・横帯それぞれに「100%領域の幅」と「片側のフェード幅」を指定できます（UV単位）。100%領域の幅は中央の帯全体の幅です。その両側に指定幅のフェードを付け、100%から0%へ滑らかに補間します。RGBAすべてを補間します。
例えば100%領域の幅0.2、片側のフェード幅0.1なら、中央の0.4～0.6を100%で重ね、0.3～0.4と0.6～0.7をフェードします。全体幅は `100%領域の幅 + 2 × フェード幅` で、最大1 UVに制限します。
100%領域の幅0では中心の継ぎ目に隣接する画素のみ100%になります。フェード幅0では100%領域の端で急に切り替わります。外周画素はオフセット結果を保ちます。
縦帯は他方の軸の移動を引き継ぎ、横帯・交差部分も合わせた4通りの移動結果を合成するため、一方の補修がもう一方の外周に継ぎ目を戻しません。
移動を有効にした軸だけを補修します。両方向をシームレスにするには左右・上下を両方有効にしてください。
奇数サイズでは実際の継ぎ目位置（半サイズ切り捨て）に帯を合わせます。フェード領域では画像が混ざるため、100%領域とフェードの幅で重なり具合を調整してください。

## 検証

`Tests/Editor` に周期性・チャンネル出力・オフセット・キャンセルのEditModeテストがあります。
パッケージのテストを利用するプロジェクトでは、Test Frameworkを導入し、必要に応じてプロジェクトのPackages/manifest.jsonの `testables` に `takolib.common` を追加してください。
